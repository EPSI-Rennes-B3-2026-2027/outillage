# GitHub Student Developer Pack

Voici la liste complète des offres actuellement affichées sur la page officielle du GitHub Student Developer Pack (environ 85 partenaires), classées par catégorie.
> Liste faite par Claude.
> Etant donné que les offres peuvent changer, vérifiez bien l'éligibilité.
>
> En cas de changement, allez engueuler `@nyvetis` sur Discord pour lui dire de mettre cette liste à jour :)
>
> Sources en bas de page.

***Attention*** : Certaines offres (Heroku, Azure, Frontend Masters, Educative) sont à temps limité, vérifiez bien quand vous en aurez besoin pour éviter de perdre ces offres pour rien.

> Les liens mènent au site de chaque partenaire, pour voir à quoi sert l'outil. Pour activer une offre, passez par la [page du pack](https://education.github.com/pack) une fois votre compte validé : c'est là que se trouvent les liens d'activation.

## Les avantages GitHub

- [GitHub Pro](https://github.com/pricing) gratuit tant que vous êtes étudiants
- [GitHub Copilot Student](https://github.com/features/copilot) : complétions de code illimitées, une enveloppe de crédits IA GitHub, et un usage limité du chat et du mode agent (modèles uniquement via la sélection automatique)
- [GitHub Codespaces](https://github.com/features/codespaces) niveau Pro, utilisable partout sur votre compte
- [GitHub Pages](https://pages.github.com) : un site par compte et par organisation, plus des sites de projets illimités
- [GitHub Campus Experts](https://education.github.com/experts) : possibilité de candidater au programme pendant vos études
- [GitHub Desktop](https://desktop.github.com) et [Octicons](https://primer.style/octicons) (gratuits pour tout le monde de toute façon)

## Hors pack : les « Experiences »

En haut de la page, GitHub propose aussi des Experiences : des parcours thématiques (Intro à Copilot, Intro à l'open source, développement mobile, data science…) qui regroupent des offres du pack avec des tutoriels et des ressources. Certains partenaires n'y apparaissent que dans ce cadre et ne font pas partie du pack lui-même :

- [OpenSauced](https://opensauced.pizza) : un outil pour repérer des projets open source et suivre vos contributions, présenté dans le parcours *Intro to Open Source*
- [NativeScript](https://nativescript.org) : un framework open source pour créer des applis mobiles natives iOS et Android en JavaScript ou TypeScript, présenté dans le parcours *Mobile App Development*

## Comment en profiter

Pour y avoir droit, allez faire une [demande d'éligibilité au pack](https://github.com/settings/education/benefits), il faudra y renseigner des informations pour vérifier qu'on est étudiant (ex : justificatif de scolarité).
